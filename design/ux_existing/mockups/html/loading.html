Loading states — Spark loader

A calm, branded replacement for plain spinners. The riffy mark breathes inside a chasing blue→orange ring, with gentle voice bars underneath — lively enough to feel alive, quiet enough for anxious practice moments.

When to use

  • Full boot — session resolve, auth guard (centered, no message or short “Starting up…”)
  • In-page — home plan, practice catalog, profile (`LoadingView` replacement)
  • Sheet — paywall offerings, modal fetches
  • Compact — button loading state (mark + ring only, no bars)

Motion rules

  • Prefer ease-in-out loops (2–3s) — no frantic spinners
  • Respect prefers-reduced-motion → static mark + opacity pulse on message only
  • Always set aria-busy="true" on the loader root
  • Messages are optional; cycle long waits every ~2.8s with a soft cross-fade
