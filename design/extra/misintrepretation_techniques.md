# Misinterpretation Techniques (archived)

The **Misinterpretation: Techniques** exercise (`misinterpretationTechniques`) has been
removed from the design backend. This file preserves the technique definitions and
examples it was built around, in case they are useful for other exercises or a future
revival.

The exercise gave the user an ordinary everyday sentence containing "I", "you", or "we",
**plus one assigned technique**, and asked them to respond as if they understood the
sentence differently — committing fully to that one technique. The eight techniques below
are the deliberate "lenses" the user picked from.

## The techniques

### 1. Literal Trap
Respond as if it's literally, physically happening — treat figurative or idiomatic
language as fact.

> "I might die tonight" → "Should I call someone, or are you handling the arrangements?"

### 2. Context Shift
Respond as if the sentence belongs to a completely different situation — romantic, legal,
medical, professional.

> "We should probably stop here" → "Already? We've only known each other a week."

### 3. Scope Explosion
Treat this small, everyday thing like it has massive, world-altering implications.

> "I always lose my keys when you're around" → "So I rearrange your entire life just by existing."

### 4. Innuendo
Find the suggestive reading of an innocent sentence — respond from there.

> "You always take so long" → "Worth every second, I've been told."

### 5. Absurd Escalation
Run with the statement to a completely ridiculous conclusion — invent a world where this
is a famous problem.

> "I can't keep up with you" → "Nobody can. Scientists are looking into it."

### 6. Pronoun Swap
Misread who a pronoun points to: take a general "you" (anyone) as personal, or split an
inclusive "we" so it means just them. The ambiguity must be real — the sentence has to
genuinely allow both readings.

> "We really made a mess of this" → "We? I watched you do all of it."

### 7. Domain Confusion
Treat casual emotional language as if it belongs to a formal domain — legal, medical,
corporate.

> "We need to talk" → "Agreed. My lawyers are available Thursday."

### 8. Temporal Shift
Misread any time reference as a wildly different duration.

> "I'll be ready in a minute" → "See you Thursday then."

## How they were used

- **Litmus test:** a real misinterpretation must *stop working* under the sentence's
  original intended meaning. If the line still makes sense as a normal reply, it isn't a
  misinterpretation.
- **Commitment is the whole skill.** Once a technique is picked, every word comes from
  inside that lens; a half-committed misread is just a weird comment.
- **Keep it short.** One or two sentences — a misread that needs three sentences is
  explaining the joke.
