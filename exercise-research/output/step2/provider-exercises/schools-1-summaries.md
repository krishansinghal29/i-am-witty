# Step 2b Provider Summaries — schools-1

Batch type: comedy / improv schools (live-online + on-demand). All six are
institutions with structured, multi-level curricula. Strong source for
codified, sequenced exercise progressions (improv ladders, joke-writing drills).

---

## Second City Training Center

- **Methodology**: Sequenced multi-level ladder (Improv 1-6, Writing, Stand-Up,
  Storytelling, Conservatory). Rooted in Viola Spolin theater games + ensemble
  "Yes, And"; progression is environment -> character -> scene -> tilts/game ->
  performance. Online courses are hybrid: self-paced assignments + live group
  workshops + weekly feedback.
- **Exercises found**: 9 (Yes-And drills, character scenes, who/what/where +
  tilts, Spolin games, archive sketch analysis, musical improv, stand-up set
  creation, storytelling story-collection, weekly writing assignments).
- **Evidence quality**: Mostly confirmed. Level descriptions are public on
  individual class pages; specific in-class exercise names are partly inferred
  (pages describe skills/themes more than named drills).
- **Cross-domain value**: Storytelling + Stand-Up + Writing tracks reach beyond
  improv into oratory, humor-jokes, and storytelling — relevant to riffy.
- **2c recommendation**: YES — deep-scrape the full class catalog to extract the
  level-by-level skill progression. Start: https://www.secondcity.com/find-a-class/virtual
  and the storytelling/public-speaking track
  https://www.secondcity.com/classes/virtual/storytelling-public-speaking

## Upright Citizens Brigade (UCB) Training Center

- **Methodology**: The most explicitly codified "game of the scene" system in
  improv. Base Reality -> First Unusual Thing -> Framing -> If/Then justification
  -> heighten 3-5x -> Harold. The UCB Comedy Improvisation Manual fully
  documents it. Reps + structured curriculum (Improv 101-401, Sketch 101-301,
  Character, Musical), 8 x 3-hour sessions each, ending in a class show.
- **Exercises found**: 10 (game-of-the-scene drill, framing, foundational scene
  work, group game drilling, beat drilling, Harold openings/Pattern Game/
  Invocation/monologues, full Harold, sketch-by-format assignments, pitch
  packets, musical improv).
- **Evidence quality**: Mostly confirmed — but via secondary sources. UCB's own
  site returns HTTP 403 to scrapers; rich detail comes from drewtarvin.com class
  notes, the IRC Improv Wiki, and Kevin Mullaney's writeups (all reliable).
- **2c recommendation**: YES — highest-value deep dive in this batch. The
  game-of-the-scene + If/Then + heightening structure converts cleanly into
  discrete, gradeable drills. Start with the drewtarvin class-notes series
  (101/201/301/401, Sketch 101/201) since ucbcomedy.com blocks fetches:
  https://drewtarvin.com/comedy/ucb-improv-301-class-notes/ and the IRC manual
  page https://wiki.improvresourcecenter.com/index.php?title=The_Upright_Citizens_Brigade_Comedy_Improvisation_Manual

## Stand Up Comedy Clinic (Jerry Corley)

- **Methodology**: "Comedy as a science" — break jokes into setup/premise/
  punchline/act-out and generate volume via formulas. Jerry (ex-Tonight Show,
  80-120 jokes/day) teaches rapid generation. 8-week live classes plus a public
  blog full of standalone, directly-extractable writing drills and a downloadable
  "Joke Writing 1-2-3" workbook.
- **Exercises found**: 8 (Three Questions method, inflection-emphasis drill,
  5-strategies-from-a-subject, listing technique, 15-jokes-in-30-min,
  Joke Writing 1-2-3 system, joke-writing challenge funnel, 8-week set workshop).
- **Evidence quality**: Confirmed and unusually concrete — the blog spells out
  step-by-step procedures with worked examples. The single best self-practice,
  no-performance-needed source in this batch for solo humor drills.
- **2c recommendation**: YES — blog is a drill goldmine that maps directly to
  riffy-style solo writing prompts. Start: https://www.standupcomedyclinic.com/category/comedy-writing/
  (plus the 1-2-3 PDF http://exer-cloak.s3.amazonaws.com/exer-cloak/joke_writing_1-2-3.pdf)

## The Groundlings School

- **Methodology**: Character-forward improv/sketch (the "SNL pipeline" school).
  Strict sequential curriculum: Basic -> Intermediate -> Writing/Improv Lab ->
  Advanced, plus a 6-session sketch-writing course (character vs premise sketch,
  beats, finding material). Emphasis on building strong solo characters via
  scenes and monologues.
- **Exercises found**: 6 (Basic games, character creation, intermediate scene
  work, Writing Lab, sketch writing, intro drop-in).
- **Evidence quality**: Mostly confirmed at the level/theme grain; specific named
  in-class games are not published (consistent with their secretive curriculum).
  Lower granularity than UCB or the Comedy Clinic.
- **2c recommendation**: NO (low priority) — methodology overlaps heavily with
  UCB/Second City and the character-monologue angle is narrower; published detail
  is thin. If revisited, start: https://groundlings.com/school/online-classes

## iO Theater (Improv Olympic)

- **Methodology**: Home of the Harold and the Del Close/Charna Halpern "Truth in
  Comedy" canon (group mind, finding the game, heightening, organic long-form).
  5-level ladder: fundamentals+Harold -> character/environment -> two-person
  scenes+editing -> long-form -> devise an original long-form for a staged run.
- **Exercises found**: 6 (fundamentals+first Harold, character/environment work,
  two-person scenes+tag-outs/walk-ons, long-form forms, devise original
  long-form, Truth-in-Comedy canon exercises).
- **Evidence quality**: Mostly confirmed for level structure; the Truth-in-Comedy
  exercises are inferred (canon is in the book, not itemized on the class page).
- **2c recommendation**: NO (covered by canon) — the actionable exercises live in
  the "Truth in Comedy" book rather than iO's site; UCB already covers the
  Harold/game system more granularly for this batch. Lower priority. If
  revisited, mine "Truth in Comedy" directly rather than https://ioimprov.com/classes/

## World's Greatest Improv School (WGIS)

- **Methodology**: Game-based long-form (UCB lineage via founder Will Hines),
  built explicitly around high-volume reps + detailed notes. "Improv grad school"
  positioning. 3-level fundamentals + Grad School advanced classes, plus a heavy
  community layer: cheap weekly drop-ins, jams, Draft Night, multi-day "Bitness".
  Online-first and notably affordable.
- **Exercises found**: 8 (Level 1 intro, Game Drill, Scene Notes, Notes &
  Adjustments, Will Hines scene class, weekend drop-ins, jam/Draft Night/Bitness,
  Grad School workshops).
- **Evidence quality**: Mostly confirmed — class/workshop titles and formats are
  public; exact in-workshop drills are partly inferred from titles.
- **2c recommendation**: MAYBE/NO — the rep-plus-notes model is conceptually
  relevant to riffy's feedback loop, but the actual game theory duplicates UCB.
  The distinctive asset is Will Hines's book "How to Be the Greatest Improviser
  on Earth," which is the better 2c target than the site. If revisited, start:
  https://www.wgimprovschool.com/about-works
