# Storytelling — Research Notes

## Run summary
- This was a **resume** run. The prior agent left 76 exercises (lines 1-76). This run appended **52 new exercises** (lines 77-128), bringing the file to **128 total**.
- All 128 lines validated as parseable JSON, correct `domain`, full schema, no duplicate or colliding names/aliases.
- Stopping point: genuine diminishing returns. By the final two search waves, queries were overwhelmingly returning variants of exercises already in the file (e.g. epiphany/distillation drills overlapping the existing "Find Your Five-Second Moment" and "Story Compression Ladder"; most improv "build-a-story" games already captured).

## Strategy: where the prior agent already had deep coverage
The first 76 entries already exhausted the obvious canon: Storyworthy (Matthew Dicks) methods, The Practice Space guide, Bobette Buster's *Do Story*, the SessionLab library, Keith Johnstone, Marshall Ganz public narrative, UNESCO/StoryCorps circles, Heather Forest folktale pedagogy, Vonnegut shapes, Pixar in a Box, six-word stories, and the common improv-storytelling games (Story Spine, Conducted Story, Story Story Die, Typewriter, Yes-And, etc.). So this run **deliberately pushed into adjacent and non-English traditions, craft frameworks, and specialist sub-fields** the prior agent hadn't touched.

## Richest sources this run (the 5 best new veins)
1. **Non-Western / world oral traditions** — rakugo (kamishimo head-turn character switching; shigusa mime-eating; kobanashi warm-up stories), West African griot (call-and-response, praise framing), Japanese kamishibai (paper-card reveal pacing), Iranian naqqali/pardeh-khani (point-and-narrate painted panels), Irish seanchaí (formulaic "runs" and refrains). These produced genuinely distinct *performance* drills, not just structure drills. (rakugonz.com, Wikipedia, allgoodtales.com, kamishibai-kai.com, UNESCO ICH, connollycove.com)
2. **Business / persuasion storytelling frameworks** turned into drills — SCQA (Minto), Sparkline (Duarte), Springboard (Denning), StoryBrand customer-as-hero + three-level problem (Miller), Epiphany Bridge (Brunson), data-story arc / Big Idea worksheet (Knaflic). (duarte.com, storybrand.com, stevedenning.com, storytellingwithdata.com, managementconsulted.com)
3. **Screenwriting / film structure adapted to oral telling** — Dan Harmon Story Circle mapping, Save the Cat beat-sheeting, Pixar's 22 Rules (#9 "what wouldn't happen", #20 rearrange), on-the-nose-then-rewrite subtext drill, the cutting exercise. (studiobinder.com, reedsy.com, scriptreaderpro.com, stage32.com)
4. **Improv Encyclopedia "Narration" category + eldrbarry games list** — surfaced named games the prior agent missed: String of Pearls, La Ronde, Pillars, Cast of Thousands, Nanofictionary, multi-POV/Rashomon. (improvencyclopedia.org, eldrbarry.net, improvdr.com)
5. **Drama-education + narrative-therapy + craft pedagogy** — Story Whoosh (RSC), Story Stones, Talking Stick circle (First Nations), Boal Image Theatre / Complete the Image, Propp function cards, the Life Timeline "stones and flowers" and externalization drills, descriptive-writing sensory walks, jump-tale / ghost-story delivery, punch-word emphasis, emotion-mapped read-aloud. (dramaresource.com, ictinc.ca, positivepsychology.com, creativewriting.co.nz, sierraclub.org, write-out-loud.com)

## Sources found but not fully mined
- **Storytelling With Data: Let's Practice! (Knaflic)** — reportedly 100+ hands-on exercises; I captured the core narrative-arc/Big Idea drill but the book's chart-specific exercises are mostly visual, not oral, so I didn't mine them deeply.
- **Toastmasters Storytelling advanced manual** — has 5 projects (folk tale, personal story, moral story, emotional story, historical figure). I captured "The Moral of the Story"; the emotional-story and historical-figure projects could yield 1-2 more drills.
- **Augusto Boal's full *Games for Actors and Non-Actors*** — Image Theatre captured, but his broader catalog (largely overlapping the improv canon already in the file) wasn't exhaustively combed.
- **Rakugo classic-story repertoire** — individual rakugo tales (Toki Udon, Meguro no Sanma, Jugemu) are scripts to learn, not drills, so left out by design.
- **Reddit/Quora threads** — direct keyword searches returned thin/no results in this environment; community-sourced personal-anecdote drills are likely under-tapped (a manual Reddit dive on r/storytelling, r/Moth-adjacent threads would probably surface a few more first-person practice routines).

## Search queries that worked well
- Naming a *tradition* + "exercises/practice/technique" (`rakugo training kobanashi exercises`, `griot storytelling techniques training`, `naqqali pardeh-khani exercises`).
- Naming a *framework author* + "drill/practice" (`Duarte sparkline drills`, `Dan Harmon story circle exercise`, `StoryBrand customer is the hero practice`).
- Mining named games from index pages, then fetching the index directly (Improv Encyclopedia Narration category, eldrbarry storytelling-games list) to harvest game names as fresh queries.
- Adjacent-field framing: `narrative journalism nut graf anecdotal lede exercises`, `narrative therapy life timeline turning points`, `screenwriting subtext on-the-nose rewrite drill`.

## Honest coverage gaps / under-covered sub-areas
- **Long-form improv formats as deliberate practice** — captured La Ronde and the foundational games, but Harold/Deconstruction/Movie/Documentary formats used *as storytelling rehearsal* are only lightly represented.
- **Children's / ESL classroom storytelling** — a few captured (Whoosh, Story Stones), but there is a large pool of structured ESL "story-club" formats that are excellent adult practice and only sampled.
- **Singing/ballad and musical storytelling** — touched via griot and seanchaí refrains, but ballad-construction and sung-narrative drills are thin.
- **Sign-language / visual-gestural storytelling (ASL)** — a known rich tradition (classifier stories, "ASL storytelling" handshape constraints) not searched this run; likely 3-5 distinct drills there.
- **Stand-up "story bit" construction** — sits between this domain and humor-jokes; the act-out, the tag, and "story-with-punchlines" structure could yield more if mined from the comedy side.
- **Memory-palace / mnemonic learning of long tales** — bards used spatial memory; only lightly captured via Story Mapping and Seanchaí runs.
- **Non-English business storytelling beyond the US/Anglo frameworks** — captured the dominant Anglo frameworks; other-language corporate storytelling pedagogy unexplored.
