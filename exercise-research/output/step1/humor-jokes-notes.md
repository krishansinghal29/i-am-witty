# humor-jokes — Research Notes

Resumed an interrupted run. Started from **61** existing exercises; appended **43 new**, for a
new total of **104** exercises in `humor-jokes.jsonl`. All lines validate as JSON; no duplicate
names; every line carries the full schema.

The prior agent had already covered the obvious stand-up writing canon (Greg Dean Joke Prospector,
Toplyn monologue/roast method, Vorhaus's Wildly Inappropriate Response + Clash of Context, GOLD
Comedy / Creative Stand-Up homework, NZ Comedy School workbook, Judy Carter's Weird-Hard-Scary-Stupid,
tags/callbacks, writers'-room alts, pun/cliché drills, timing/pause work, set-review routines,
Toastmasters humor, single-subject strategies, Seinfeld chain). So this resume deliberately pushed
into adjacent traditions the first pass under-mined.

## Richest sources (this run)
1. **Chris Head's 25-lesson stand-up writing course + craft posts** (chrishead.com) — the Lesson 11
   "Writing Wordplay One-liners" page alone yielded ~6 distinct one-liner drills (statistic
   afterthoughts, saying recompletion, idiom beforethoughts, hide-the-payoff-word, inspirational-quote
   knockdown). Also heckler-response drills, persona, sketch structure (setup-reveal-escalation),
   and the three-perceptual-positions storytelling frame.
2. **Improv game libraries** (ImprovDr.com, learnimprov.com, improvencyclopedia.org, ImprovWiki,
   ponies/poniesimprov) — joke-specific and wit-specific games not in the file: Ninety-Nine Jokes,
   World's Worst, Good-Bad-Worst Advice Panel, New Choice/Ding, Alphabet Scene, Scenes From a Hat,
   Gibberish Translation, Press Conference/Expert, Object Transformation/Props.
3. **UCB Sketch/Improv 201 notes** (Drew Tarvin's class notes + ucbcomedy.com) — the if-then
   heightening engine and find-the-game script diagnosis, the core "game of the scene" discipline
   the first pass only touched via the 101 parody assignment.
4. **Comedy-book summaries** (The Comic Toolbox throughline/tension-release via laughtome; Comedy
   Writing Secrets THREES via thecomedycrowd + Time; The Comedy Bible act-out/space-work and
   topic+attitude premise via academia.edu/bigbencomedy) — extracted drills the prior pass hadn't
   pulled from these same books.
5. **Conversational-humor / banter pedagogy** (francescopecoraro.com, scienceofpeople.com,
   socialself.com, jaunty.org) — turned banter advice into concrete reps: intentional
   misinterpretation, amplify-and-agree, affectionate tease+compliment, useless-superpower question
   bank, 1-minute association lists.

Honorable mentions: Weird Al / The Spiel Guy (song parody), Comedians on the Loose (blind-spot
persona, two-column comparison, ride-home review already present), Just a Minute (BBC), English
Comedy Frankfurt (Armando-style premise deconstruction; act-emotion drills present from prior pass).

## Search queries that worked
- Pulling a known book's tool names into the query (`"The Comic Toolbox" ... "tension and release"
  "the comic throughline"`, `"Comedy Writing Secrets" Helitzer "THREES"`) reliably surfaced
  chapter summaries with the underlying drill.
- Quoting an improv game name plus "comedy/funny/practice" (`"World's Worst"`, `"Ninety-Nine Jokes"`,
  `gibberish ... translate funny`) found game-library pages with full procedures.
- For conversational wit, combining technique terms (`"amplify and agree" "intentional
  misinterpretation" banter drills`) found listicles I could convert into reps.
- `filetype`-style and "lesson index" chasing (finding Chris Head's "ALL 25 LESSONS INDEX") was the
  single highest-yield move — one teacher's numbered curriculum = many distinct drills.

## Sources found but not fully mined (leads for a future pass)
- **Chris Head's full 25-lesson index** — only Lessons 8 and 11 were opened. Lessons on observational
  jokes, persona, storytelling techniques, act-outs, and sketch likely contain several more discrete
  drills.
- **Joe Toplyn, Comedy Writing for Late-Night TV** — the monologue method and roast method are in
  the file, but his desk-piece, sketch, and "Possible Outcomes" tools weren't extracted as drills.
- **Steve Kaplan, The Hidden Tools of Comedy** — straight/wavy line and the comic-premise "lie that
  tells the truth" are concepts; the book's actual exercises weren't located in summaries.
- **Second City writing curriculum** — the public pages are class descriptions, not drills; the
  named building blocks (Simple Yet Impossible Goal, character studies, dialogue exercises) are real
  exercises but full procedures need a handout/syllabus PDF.
- **ClownAntics / Church of Clown / clown-pedagogy** — repeatedly 403'd or only listed concepts
  (discovery, flop, status, red nose). Physical/clown comedy is real, in-scope exercise territory
  that's under-mined here (only Character Physicality Walk + Object Transformation made it in).
- **Reddit r/Standup / comedy podcasts** — search returned almost nothing usable directly;
  practitioner-described daily routines would need direct thread reading.

## Honest coverage gaps / under-covered sub-areas
- **Physical & clown comedy** (slapstick mechanics, status transactions, the "flop," bouffon,
  prop-gag construction) — thinly represented; blocked sources hurt here.
- **Sketch writing beyond structure** — only a few sketch drills (parody one-change from prior pass,
  if-then heightening, setup-reveal-escalation, the Second City "animal/parody" assignment families).
  Sketch act-break/runner/sketch-revue construction is light.
- **Late-night / topical formats** beyond the monologue (desk pieces, fake ads, correspondent bits).
- **Improv-for-stand-up speed games** — captured a solid set, but the short-form canon is deep;
  many more speed/wit games exist (Forward-Reverse, Should've Said, Sound Effects, Da Doo Ron Ron /
  song games, Sit-Stand-Lean style constraint games).
- **Non-English / other-culture comedy traditions** — only lightly reached (Just a Minute is British;
  Spring Festival Gala xiangsheng/crosstalk and other traditions surfaced in passing but no
  concrete xiangsheng drills were captured). A real gap.
- **Deadpan/sarcasm and delivery micro-skills** — one deadpan drill added; sarcasm-specific and
  act-out-emotional-filter work is otherwise mostly from the prior pass.

Diminishing returns reached: by the final two waves, heightening/escalation/association/premise-mining
queries were returning variants of exercises already in the file. The most promising untapped veins
are physical/clown comedy and full teacher curricula (Chris Head's remaining lessons, Toplyn's other
tools) that sit behind PDFs or paywalls rather than free article pages.
