## What the prior agent already covered well (so this run deliberately avoided)

Booty, Samurai, etc.), the agreement/yes-and family, the canonical short-form games

## Richest sources
1. **New York Improv Theater master game list**
   (`newyorkimprovtheater.com/improv-games-master-list/`) — ~800 game names; the best
   single index for mining names to chase down individually.
2. **Improv Illusionist exercises page** (`improvillusionist.com/exercises/`) — ~59
   detailed physical/object/environment/scene drills with full procedures; unusually
   well-described and largely absent from the prior catalog.
3. **Canadian Improv Games practice games** (`improv.ca/practice-games/`) — ~29 clean
   named scene games with crisp how-to text.
4. **ImprovDr "Game Library" series** (`improvdr.com`) — per-game deep dives with
   procedure and coaching notes (Rashomon, La Ronde, Da Doo Ron Ron, Tag-Team
   Monologue, Genre Rollercoaster, Endowment Circle).
5. **Improv Encyclopedia + improwiki** (`improvencyclopedia.org`, `improwiki.com`) —
   authoritative procedures for individual named games and warmups.
   Honorable mentions: SessionLab, Hoopla, learnimprov, Drama Notebook, Rehearsals
   for Growth (emotional/connection drills), and the UCB Manual via IRC Improv Wiki.

## Search queries that worked
- Mining specific game NAMES as queries (e.g. `"Pillars" "La Ronde" "Da Doo Ron Ron"
  ... procedure`) — by far the most efficient once a master list was found.
- `UCB manual game of the scene if-then first unusual thing`
- `musical improv exercises drills you can do at home`
- `Boal games for actors and non-actors "the great game of power"`
- `improv warmup "Mexican Name Wave" "Honey I Love You" how to play`
- `solo improv exercises monologue monoscene ghosting`

## Sources found but not fully mined
- **NYIT master list (~800 names)**: only the well-known, clearly-distinct games were
  written up. Dozens of long-tail entries (e.g. Goon River, Sybil, Janus Dance,
  Liquid Change, French Braid, Cloud Atlas, Bidirectional Satellite TV) remain
  un-researched — many are theatre-specific or long-form formats rather than practice
  drills, but a few may be capturable with dedicated lookups.
- **Boal's *Games for Actors and Non-Actors*** (200+ games) — only a handful captured
  this run plus prior; the trust/sensory/image-theatre catalog could yield 20-40 more
  applied-theatre exercises. The full PDF is online but wasn't deep-mined.
- **UCB Manual full text** — only the If-Then framework was extractable from wiki
  summaries; the book's exercise appendices weren't reachable.
- **The IESA ImprovOlympic handout PDF** existed but couldn't be rendered (no PDF
  tooling in this environment) — likely contains more warmups.
- **Non-English traditions** (commedia dell'arte lazzi, Japanese/European improv
  scenes, Theatre of the Oppressed beyond Boal's named games) — barely touched; a
  real coverage gap.

## Honest coverage gaps / under-covered sub-areas
- **Long-form formats as practice** — captured the practice-friendly ones (La Ronde,
  Documentary, Harold opening drills implied) but full formats (Armando, Deconstruction,
  Movie, Monoscene-as-format, Living Room, JTS Brown, Close Quarters) are mostly absent;
  they're arguably formats not drills, so this is a judgment-call gap.
- **Commedia dell'arte and clown** — lazzi, status masks, bouffon, and clown
  exercises (red-nose work, "the flop") are essentially untouched.
- **Music/rhythm depth** — got the core musical games but not advanced harmony/
  counterpoint drills, beatbox/vocal-percussion exercises, or sung-format practice.
- **Applied/corporate & therapeutic improv** (drama therapy, playback theatre,
  Rehearsals-for-Growth couples work) — only lightly sampled.
- **Accents/dialects and physical-comedy specifics** (takes, spit-takes, the double
  take, slow burn) — minimal; overlaps voice-tonality but has improv-specific drills.
